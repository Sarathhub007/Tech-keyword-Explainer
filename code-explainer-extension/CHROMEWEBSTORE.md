## Store Listing

**Extension Name**
CodeWord Explainer

**Short Description**
Double-click any programming keyword on any webpage to instantly view definitions, code examples, and reference docs.

**Detailed Description**
Double-click any programming keyword or technical concept while browsing, reading tutorials, or reviewing code to instantly see comprehensive explanations, practical syntax examples, and links to official documentation.

Key features:
- Double-click any programming keyword anywhere on the web (Medium, GitHub, StackOverflow, documentation sites, tutorials)
- Over 150+ built-in concepts across JavaScript, TypeScript, Python, OOP, Data Structures, Algorithms, DevOps, and Databases
- Realistic syntax code snippets with a 1-click copy button
- Audio speech pronunciation: hear technical terms pronounced and explained out loud
- Clean, non-intrusive popup card with dark and light theme options
- Built-in search bar in the extension menu for quick on-demand lookups
- Works 100% offline with zero external network tracking or latency

How to use:
1. Double-click on any coding term or keyword on any webpage.
2. An interactive explanation card appears right next to the word with its definition, details, and example.
3. Click the speaker icon to listen to the audio explanation, or click "Official Docs" for deep dives.
4. Press Escape or click anywhere outside to dismiss the card.

Privacy & Permissions:
CodeWord Explainer runs entirely within your browser and does not collect, transmit, or sell any personal data or browsing history.
